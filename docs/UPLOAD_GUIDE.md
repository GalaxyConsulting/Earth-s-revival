# Инструкция по загрузке и редактированию сайта

## 📦 Загрузка архива сайта

### Метод 1: Через командную строку (рекомендуется)

1. **Подготовьте рабочее окружение:**
   ```bash
   git clone https://github.com/GalaxyConsulting/Earth-s-revival.git
   cd Earth-s-revival
   ```

2. **Скопируйте ваш ZIP-архив в папку репозитория:**
   ```bash
   # Например, если архив называется site.zip
   cp /путь/к/вашему/site.zip .
   ```

3. **Распакуйте архив в папку website:**
   ```bash
   # Удалите существующие файлы (если нужно)
   rm -rf website/*
   
   # Распакуйте архив
   unzip site.zip -d website/
   
   # Если структура архива содержит вложенную папку, переместите файлы:
   # mv website/название-папки/* website/
   ```

4. **Проверьте структуру файлов:**
   ```bash
   ls -la website/
   # Убедитесь, что index.html находится в корне website/
   ```

5. **Зафиксируйте изменения:**
   ```bash
   git add .
   git commit -m "Добавлены файлы сайта из архива"
   git push
   ```

### Метод 2: Через GitHub Web Interface

1. Откройте https://github.com/GalaxyConsulting/Earth-s-revival
2. Перейдите в папку `website`
3. Нажмите "Add file" → "Upload files"
4. Перетащите файлы из распакованного архива
5. Напишите commit message и нажмите "Commit changes"

### Метод 3: Через GitHub Desktop

1. Откройте репозиторий в GitHub Desktop
2. Распакуйте ваш архив локально
3. Скопируйте содержимое в папку `website/` репозитория
4. GitHub Desktop автоматически обнаружит изменения
5. Напишите описание изменений и нажмите "Commit" и "Push"

## ✏️ Редактирование файлов сайта

### Основные файлы для редактирования

1. **index.html** - главная страница
2. **css/style.css** - стили сайта
3. **js/main.js** - JavaScript код

### Процесс редактирования

1. **Откройте файл в редакторе:**
   - VS Code (рекомендуется)
   - Sublime Text
   - Notepad++
   - Любой другой текстовый редактор

2. **Внесите изменения**

3. **Сохраните файл**

4. **Проверьте изменения локально:**
   ```bash
   cd website
   python -m http.server 8000
   # Откройте http://localhost:8000
   ```

5. **Зафиксируйте изменения:**
   ```bash
   git add .
   git commit -m "Описание внесенных изменений"
   git push
   ```

## 🐛 Решение проблем

### Сайт не отображается локально

- Проверьте, что вы запустили локальный сервер
- Убедитесь, что `index.html` находится в корне `website/`
- Проверьте консоль браузера на ошибки (F12)

### Изменения не отображаются

- Очистите кэш браузера (Ctrl+Shift+R или Cmd+Shift+R)
- Проверьте, что файл сохранен
- Убедитесь, что редактируете правильный файл

### Ошибки при распаковке архива

```bash
# Проверьте формат архива

# Попробуйте другую команду распаковки

# Или используйте графический интерфейс для распаковки
```
