# Руководство по внесению изменений

## 🤝 Как внести свой вклад

Мы рады вашему участию в проекте Earth's Revival! Это руководство поможет вам начать работу.

## 📋 Типы изменений

### 1. Загрузка архива сайта
- Следуйте инструкциям в [docs/UPLOAD_GUIDE.md](docs/UPLOAD_GUIDE.md)
- Используйте скрипт `extract-archive.sh` для автоматической распаковки

### 2. Редактирование контента
- Текстовые изменения в HTML файлах
- Обновление изображений
- Изменение мета-тегов и SEO

### 3. Стилизация
- Изменения в CSS файлах
- Обновление цветовой схемы
- Адаптация под мобильные устройства

### 4. Функциональность
- Добавление JavaScript кода
- Интеграция новых компонентов
- Улучшение производительности

## 🔄 Процесс работы

### Шаг 1: Подготовка

```bash
# Клонируйте репозиторий
git clone https://github.com/GalaxyConsulting/Earth-s-revival.git
cd Earth-s-revival

# Создайте новую ветку для ваших изменений
git checkout -b feature/описание-изменения
```

### Шаг 2: Внесение изменений

```bash
# Внесите необходимые изменения в файлы
# Используйте ваш любимый редактор

# Проверьте изменения локально
cd website
python -m http.server 8000
# Откройте http://localhost:8000 в браузере
```

### Шаг 3: Тестирование

Убедитесь, что:
- [ ] Сайт корректно отображается в разных браузерах
- [ ] Все ссылки работают
- [ ] Изображения загружаются
- [ ] Нет ошибок в консоли браузера (F12)
- [ ] Сайт адаптирован под мобильные устройства

### Шаг 4: Фиксация изменений

```bash
# Добавьте измененные файлы
git add .

# Создайте commit с описательным сообщением
git commit -m "Краткое описание изменений"

# Отправьте изменения на GitHub
git push origin feature/описание-изменения
```

### Шаг 5: Pull Request

1. Откройте репозиторий на GitHub
2. Нажмите "Compare & pull request"
3. Заполните описание изменений
4. Дождитесь review и одобрения

## 📝 Стандарты кода

### HTML
- Используйте семантические теги
- Добавляйте alt-теги к изображениям
- Валидный HTML5 синтаксис

### CSS
- Используйте понятные имена классов
- Группируйте связанные стили
- Комментируйте сложные конструкции
- Используйте современный CSS (Flexbox, Grid)

### JavaScript
- Используйте `const` и `let` вместо `var`
- Добавляйте комментарии к сложной логике
- Обрабатывайте ошибки
- Используйте современный ES6+ синтаксис

## 🔍 Чек-лист перед отправкой

- [ ] Код протестирован локально
- [ ] Нет ошибок в консоли
- [ ] Commit messages осмысленны
- [ ] Изменения минимальны и сфокусированы
- [ ] Документация обновлена (если нужно)
- [ ] Файлы .gitignore настроены корректно

## 🐛 Сообщение об ошибках

При обнаружении ошибки:

1. Проверьте, что ошибка воспроизводится
2. Создайте Issue на GitHub
3. Опишите:
   - Что произошло
   - Что ожидалось
   - Шаги для воспроизведения
   - Скриншоты (если применимо)

## 💬 Общение

- **Pull Requests** - для обсуждения конкретных изменений
- **Discussions** - для общих вопросов

## 📜 Соглашение о коммитах

Используйте следующий формат для commit messages:

```
Тип: Краткое описание (до 50 символов)

Более подробное описание (опционально)
```

**Типы коммитов:**
- `feat:` - новая функциональность
- `fix:` - исправление ошибки
- `docs:` - изменения в документации
- `style:` - форматирование, отступы, и т.д.
- `refactor:` - рефакторинг кода
- `test:` - добавление тестов
- `chore:` - обновление зависимостей, конфигурации

**Примеры:**
```
feat: Добавлена галерея изображений на главную страницу
fix: Исправлена навигация на мобильных устройствах
docs: Обновлена инструкция по загрузке архивов
style: Улучшена цветовая схема кнопок
```
