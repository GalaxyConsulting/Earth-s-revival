# Earth's Revival - Возрождение Земли

Репозиторий для веб-сайта проекта "Earth's Revival".

## 🚀 Быстрый старт

### Загрузка архива сайта

Если у вас есть архив сайта в формате ZIP:

1. **Склонируйте репозиторий** (если еще не сделали):
   ```bash
   git clone https://github.com/GalaxyConsulting/Earth-s-revival.git
   cd Earth-s-revival
   ```

2. **Загрузите ZIP-архив** в корень репозитория или в папку `website/`

3. **Распакуйте архив**:
   ```bash
   # Если архив в корне репозитория:
   unzip your-archive.zip -d website/
   
   # Или если хотите распаковать в корень:
   unzip your-archive.zip
   ```

4. **Удалите архив** (необязательно, он автоматически игнорируется git):
   ```bash
   rm your-archive.zip
   ```

5. **Зафиксируйте изменения**:
   ```bash
   git add .
   git commit -m "Add website files"
   git push
   ```

### Альтернативный метод через GitHub Web Interface

1. Перейдите на страницу репозитория на GitHub
2. Нажмите "Add file" → "Upload files"
3. Перетащите ваш ZIP-архив
4. После загрузки, распакуйте его локально и загрузите содержимое

## 🛠️ Разработка

### Локальный сервер для разработки

Для просмотра сайта локально используйте один из следующих методов:

**Python 3:**
```bash
cd website
python -m http.server 8000
# Откройте http://localhost:8000 в браузере
```

**Python 2:**
```bash
cd website
python -m SimpleHTTPServer 8000
```

**Node.js (http-server):**
```bash
npx http-server website -p 8000
```

**PHP:**
```bash
cd website
php -S localhost:8000
```

### Редактирование файлов

После распаковки архива, вы можете редактировать файлы напрямую:

1. Откройте нужный файл в текстовом редакторе
2. Внесите изменения
3. Сохраните файл
4. Обновите страницу в браузере для просмотра изменений

## 📝 Примеры команд для работы с архивами

### Создание архива
```bash
# Создать ZIP-архив из папки website
zip -r website-backup.zip website/

# Создать TAR.GZ архив
tar -czf website-backup.tar.gz website/
```

### Просмотр содержимого архива
```bash
# Посмотреть содержимое ZIP без распаковки
unzip -l your-archive.zip

# Посмотреть содержимое TAR.GZ
tar -tzf your-archive.tar.gz
```

### Распаковка с сохранением структуры
```bash
# Распаковать ZIP с созданием подпапок
unzip your-archive.zip -d website/

# Распаковать TAR.GZ
tar -xzf your-archive.tar.gz -C website/
```
