# Earth's Revival - Возрождение Земли

🌍 Официальный сайт инициативы Earth's Revival - глобального движения за восстановление экологического баланса планеты.

## О проекте

Earth's Revival - это веб-платформа, представляющая глобальную инициативу по восстановлению и защите окружающей среды. Сайт создан для информирования, вовлечения и мобилизации людей по всему миру.

## Структура проекта

- `index.html` - главная страница сайта
- `styles.css` - стили и дизайн
- `script.js` - интерактивные элементы и функциональность

- ✅ Современный интерфейс с экологичным дизайном
- ✅ Интерактивное меню для мобильных устройств

## Как использовать

Просто откройте `index.html` в браузере или разверните на веб-сервере:

```bash
# Локальный запуск с Python
python3 -m http.server 8080

# Или с Node.js
npx http-server
```

Затем откройте http://localhost:8080 в браузере.
